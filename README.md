# The Daily Bean

## Description
A simple, responsive website for The Daily Bean coffee shop, built with HTML and CSS.
## Features

- Responsive Design: Optimized for mobile, tablet, and desktop viewing
- Fixed Navigation: Easy navigation between Home, About, Services, and Contact pages
- Main Section: Engaging main content areas on each page
- Image Gallery: Visual showcase of the café's ambiance and offerings
- Contact Information: Email, phone, and address details for customer inquiries

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Responsive design with media queries

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/myhtmlcssproject.git
   ```

2. Navigate to the project directory:
   ```bash
   cd myhtmlcssproject
   ```

3. Open `home.html` in your web browser to view the site.

## Usage

Simply open any of the HTML files (`home.html`, `about.html`, `services.html`, `contact.html`) in a modern web browser to view the website. No server setup is required as this is a static site.
